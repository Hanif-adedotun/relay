# Updated Vision

Relay is a messaging-first orchestration platform for AI coding agents.

Relay enables developers to interact with software projects entirely through iMessage while delegating software engineering tasks to pluggable coding agents.

Relay itself is not a coding model.

Relay provides:

* Messaging interface
* Repository management
* Agent orchestration
* Deployment workflows
* Job tracking
* Notifications
* Approval workflows

Relay integrates with existing coding agents such as:

* Claude Code
* OpenClaw
* OpenHands
* Aider
* Future agent frameworks

The goal is to become the universal control plane for AI software engineering workflows.
